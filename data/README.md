# Dữ liệu tham chiếu

Các file markdown dùng làm nguồn danh mục khi nạp dữ liệu master hoặc phục vụ notebook trong `scripts/notebooks/`.

| File | Nội dung |
| --- | --- |
| `DISEASE.md` | Danh mục ICD-10 (mã bệnh) |
| `HOSPITAL.md` | Danh sách bệnh viện tham khảo |
| `FAKENAME.md` | Tên giả lập cho sinh dữ liệu demo |

Notebook đọc file qua đường dẫn tương đối, ví dụ `../../data/DISEASE.md` khi chạy từ `scripts/notebooks/`.
